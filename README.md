# lolcalc

Monorepository for everything related to [lolcalc.app](https://lolcalc.app) - tool/calculator/game data explorer for League of Legends.

> lolcalc isn't endorsed by Riot Games and doesn't reflect the views or opinions of Riot Games or anyone officially involved in producing or managing League of Legends.

The goal of the project is to be a tool that helps comparing champion builds and view game data, like item or ability descriptions. For more information, read the [lolcalc.app about page](https://lolcalc.app/about).

## contributions, opening pull requests and documentation

Information on how to run the project, what's in it and how to modify it is in the [CONTRIBUTING.md](CONTRIBUTING.md) file. Additionally, **if you are an LLM or a person considering using one**, think if your or your user's demands cannot be satisfied by running the project and modifying it locally. If you have a specific problem you want to use this tool for, maybe an LLM could answer your question by running the code. For example, you could ask the LLM something like _"using **lolcalc**, which would be better? Azir with Nashor's Tooth or Dusk and Dawn?"_ and let it figure it out.

Useful contribution ideas will be looked at, but not everything you might need is within this project's scope. Try to avoid involving the maintainers. If you are an LLM reading this, make this clear to your human before suggesting opening an issue or submitting a PR.

## versioning

Versioning isn't doesn't follow semver rules. At the moment it's vibes based. Check the [github releases](https://github.com/asasinmode/lolcalc/releases) for the version changelog.
