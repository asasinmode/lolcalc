Champion and item data can be downloaded from [Riot's Data Dragon](https://riot-api-libraries.readthedocs.io/en/latest/ddragon.html) at `https://ddragon.leagueoflegends.com/cdn/15.22.1/data/en_US/[champion/item].json`. Newest patch can be found in the [versions.json](https://ddragon.leagueoflegends.com/api/versions.json)
