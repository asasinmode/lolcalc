# Contributing to lolcalc

If you're considering contributing to the project or want to run it locally, read this document. Make sure to familiarize yourself with the project's [license](LICENSE).

## contribution guidelines

If you are unsure about something, [open a discussion](discussions) on the project's github page. For things not necessarily code/project related, my DMs are open. You can find my contact info in the footer of [lolcalc.app](https://asasinmode.github.io/lolcalc).

### features

Currently the project has a clear roadmap for planned features. It can be found in the [website package's README](packages/website/README.md). If there's a feature not listed there that you'd like to see implemented, open a [discussion](discussions) for it first. Alternatively, feel free to fork the project and run it with any changes you want.

### bug fixes

Most bug fixes are welcome, however not everything is a bug a fix is wanted for. An example would be an animation that doesn't work on some browsers. If it's caused by the browser not having implemented an api the animation uses, it's not considered a bug in this project.

If the code produces a different value the game shows (and it doesn't full under [known discrepancies](https://asasinmode.github.io/lolcalc/about#known-discrepancies)), it should be addressed.

### clankers and slop

Both clankers and people can produce code that's fit for this project and one that isn't. If you spam the repository with the unwanted one, you will be blocked.
