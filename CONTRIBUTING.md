# contributing to lolcalc

If you're considering contributing to the project or want to run it locally, read this document. Make sure to familiarize yourself with the project's [license](LICENSE).

## contribution guidelines

If you are unsure about something, [open a discussion](discussions) on the project's github page. For things not necessarily code/project related, my DMs are open. You can find my contact info in the footer of [lolcalc.app](https://asasinmode.github.io/lolcalc).

### features

Currently the project has a [list of planned features](ROADMAP.md). If there's a feature not listed there that you'd like to see implemented, open a [discussion](discussions) for it first. Alternatively, feel free to fork the project and run it with any changes you want.

### bug fixes

Most bug fixes are welcome, however not everything is a bug a fix is wanted for. An example would be an animation that doesn't work on some browsers. If it's caused by the browser not having implemented an api the animation uses, it's not considered a bug in this project.

If the code produces a value different from what the game shows (and it doesn't fall under [known discrepancies](https://asasinmode.github.io/lolcalc/about#known-discrepancies)), it should be addressed. Please open an issue, making sure to provide in-game screenshots/a video of the discrepancy. Calculation issues reported without them will be ignored.

### clankers and slop

Both clankers and people can produce code that's fit for this project and one that isn't. If you spam the repository with the unwanted one, you will be blocked.

### creating pull requests

Pull requests are currently available only to collaborators. While you can't open one directly, if you have something ready to go you can always link to the fork with changes in an issue.

## project guide

This project consists of 4 main packages + mini scripts package.

- [core](packages/core/README.md) the main "standalone" package for game logic related things.
- [website](packages/website/README.md) the [lolcalc.app](https://asasinmode.github.io/lolcalc) website.
- [data](packages/data/README.md) the data used by lolcalc, mostly extracted from the game files provided by [community dragon](https://communitydragon.org/). Most of it is generated by the [updateData script](scripts/updateData.ts)
- [shared](packages/shared/README.md) misc consts, helpers and utils reused throughout the codebase.
- **scripts** self explanatory

The overall structure is: _update data script_ pulls game data, _core package_ contains logic that turns that data into `DamageSources`, the _website_ is an interface for interacting with them.

## scripts

The root `scripts` directory contains the following

### updateTestFixture

Used for updating game data test fixtures with specific properties

```sh
node .\scripts\updateTestFixture.ts [patch] -i [item id or search query] -c [champion id]:[ability keys separated by commas] -d [dragon name]:[stack|soul] -e [effect object name]

# add vladimir and his Q and passive
node .\scripts\updateTestFixture.ts 16.16 -c Vladimir:passive,q

# add shadowflame and randuin
node .\scripts\updateTestFixture.ts 16.16 -i shadowflame -i 3143

# add infernal stack & mountain soul
node .\scripts\updateTestFixture.ts 16.16 -d infernal:stack -d mountain:stack

# add ghost and botrk slow effects
node .\scripts\updateTestFixture.ts 16.16 -e SummonerHaste -e 3153
```
